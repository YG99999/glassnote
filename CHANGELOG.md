# Changelog

## 0.1.0 — 2026-10-22

First public Windows release.

- Frozen full-screen and region capture with a tray action, global hotkey, and desktop shortcut.
- Compact glass recorder, local live English transcription, editable text, and appended takes.
- Drawing tools and numbered notes with inline typing or dictation.
- Light/dark library with named projects, one level of numbered subfolders, and collapsing.
- Agent-readable folder snapshots and ZIP exports with linked screenshots and notes.
- Recovery of unfinished captures, atomic metadata writes, and retained audio on failure.
- Reduced motion, opaque glass fallback, keyboard focus, stable text selection and scrolling.
