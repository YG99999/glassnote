# Glassnote 0.1.1

A small update to keep project folders tidy and make closing captures predictable.

- Subfolders always show 0, 1, 2, …; deleting one shifts the following numbers down. Capture IDs, contents, and selected destinations remain linked.
- Existing libraries automatically close numbering gaps on startup.
- × and Escape discard a capture, including its autosaved edits. Active audio is stopped and processing finishes before its files are removed.
- Save discards a bare screenshot or empty numbered note. Typed notes, transcripts, drawings, and retained voice recordings are saved normally.

Windows 11 x64. Install over the previous version; projects and recordings remain on this computer. The installer is unsigned, so Windows may show a reputation warning. Download SHA256SUMS.txt to verify its checksum.
