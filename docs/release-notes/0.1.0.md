Glassnote is a Windows screenshot notebook with offline English voice notes and numbered annotations.

### Download

Install **Glassnote_0.1.0_x64-setup.exe** on **Windows 11 x64**. This is a per-user installation with a desktop capture shortcut. No admin access or account is required. Releases are currently **unsigned**; Windows may show a publisher warning. SHA-256 checksums are attached.

### Capture, explain, save

- Tap for a full-monitor capture or drag a region with `Ctrl+Alt+S` or the desktop shortcut.
- Keep the desktop frozen while you draw, add numbered notes, or record.
- See local English dictation, edit the transcript, and append more takes.
- Save to projects or numbered subfolders without opening the library.
- Copy a prepared folder path or export a ZIP with actual PNGs and concise linked Markdown for people and AI agents.

Download the ~32 MB Whisper tiny.en model once in Settings to enable speech. Screenshot-only use works immediately. Speech runs locally on an AVX2-compatible x64 CPU (FMA, F16C, BMI2); unsupported CPUs can still use screenshots and typed notes. There is no telemetry or cloud transcription.

### Early release

19 Rust tests and browser checks cover existing paths. The native installer and local speech engine have been exercised on Windows 11. Mixed-DPI multi-monitor hardware, microphone unplugging, and the latest native clipboard/ZIP picker need more hands-on coverage. English transcription accuracy varies; see [verification](https://github.com/YG99999/glassnote/blob/main/VERIFICATION.md).
